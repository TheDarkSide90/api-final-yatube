# api_yatube
api_yatube

Проект с тестовым API для авторов. Можно добавлять посты, комментировать их, а также следить за автором поста.

Клонировать репозиторий и перейти в него в командной строке:

```bash
git clone https://github.com/TheDarkSide90/api-final-yatube.git
```

```bash
cd api-final-yatube
```

Cоздать и активировать виртуальное окружение:

```bash
python -m venv env
```

Перейти в рабочую папку:

```bash
cd yatube_api
```

Запустить проект:

```bash
python manage.py runserver
```
